# 📱 Human Activity Recognition (HAR) Using Smartphone Sensors

This project develops an end-to-end machine learning classification pipeline to accurately predict six daily physical activities (`Laying`, `Sitting`, `Standing`, `Walking`, `Walking Upstairs`, and `Walking Downstairs`) using 561-dimensional signal features extracted from smartphone accelerometer and gyroscope sensors. Following a thorough exploratory data analysis that exposed severe multicollinearity—with over 22,000 feature pairs exhibiting correlation coefficients $|r| > 0.8$—the dataset was partitioned using a 70/30 stratified train-test split to preserve precise class balances, followed by systematic benchmarking across standard, L1-regularized (Lasso), and L2-regularized (Ridge) Multiclass Logistic Regression models tuned with 4-fold cross-validation (`LogisticRegressionCV`). Through this approach, L1 regularization successfully induced sparsity by zeroing out redundant weights for automated feature selection, while L2 regularization stabilized coefficient variance across correlated signals, yielding exceptional generalization on unseen test data with the **L2 Ridge model achieving peak performance at 98.67% accuracy, 0.9867 weighted F1-score, and 0.9919 ROC-AUC**, implemented entirely in Python using `scikit-learn`, `pandas`, `numpy`, `seaborn`, and `matplotlib`.
